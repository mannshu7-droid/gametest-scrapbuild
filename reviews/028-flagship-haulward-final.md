## サイクル34の総括（4回を通じて何を検証したか）

027-finalの提案(1)「026-tremorspireの救助の罰を027-emberstakeの形に置き換える」を、本命統合ゲームで検証した。026では死を救助に置き換えたことで
防衛に投資しない攻勢（bare）が全戦略に54〜72/80で勝った。028の問いは「倒れて失う物を抱えた積荷と揺れに限り、揺れを凸の被ダメージに結びつければ、
防具・塔への投資は救助ありでも価値を持つか」。合格線は**bareが過半数で勝つ相手が無いこと**。

1. **v1**: 026をフォークし、救助で失う物を抱えた積荷（鉱石＋撃破の懸賞）と揺れだけにした。凸の被ダメージ・防具・多芸は高くつく・踏ん張り1日1回・
   塔の圏で倒れたら積荷の半分を届ける、を移植。bareの勝ちは54〜72/80→34〜60/80に下がったが、まだ5〜6戦略に過半数で勝った
2. **v2**: 合格線に効いたのは規則ではなく**検証ボットの帰還線**だった（慎重な6戦略を注意線30で帰らせると5〜6/7→2〜3/7）。遠征で通った圏を見張る・
   踏ん張りの受け止めを追加。防具は「安い時だけ上限を動かし、その時bareの支配が戻る」トレードオフが残った
3. **3回目**: 防具と撃破の揺れボーナスを塔の見張りの下に限り（塔が無いと防具を売らない）、安い防具でもbareの支配が戻らないようにした
4. **4回目（本レビュー）**: コード無変更のまま、9戦略×80シード×2組（1〜80・81〜160）を既定・`--preset 026`・v2の規則・防具なし・
   `--delay 30/60`で、固定閾値の掃引（T30/45/60/75、防具あり/なし）と`--greedy 40`を1〜80で取り直した（15条件、計15120ラン）。
   ブラウザでヘッドレスとの一致と「ボットを止めて粘る」観察を行った

## 定性評価（ブラウザAIP実プレイ）

- 方法: `npm run build` → `node tools/single-html.mjs games/028-flagship-haulward` → `headless/simulate.ts`を`__BOTLIB__`にバンドルして単一HTMLへ埋め込み、
  `file://`で開いて`__AIP__.takeControl()`のあと`reset/step`で動かした（1ランを4〜5回の呼び出しに分割）
- weave/bare/p01 × seed 501 の3ランがヘッドレスと完全一致（上記）
- **ボットを止めて粘る観察**（pusher seed 502）: tick6911・回廊の外x52・揺れ38・HP97/100・積荷¥28・防具Lv2・踏ん張り1・塔の見張り50%で、
  帰らずにその場で戦い続けた。揺れは10秒で38→71（被ダメ×1.34→×2.70）まで上がり、そこで敵の数発でHP100→47、
  10.4秒で受け止めが効いてHP15で踏ん張りが発動、その1.6秒後に倒れた。積荷¥36のうち¥18を塔の見張りが拾って届け、¥18を失った
  （救助の報告: 手当て0・費用0・ホーム無事）。「被ダメ×2を超えた辺りで急に削れる」凸の手触りと、踏ん張り→倒れるの短さが分かる
- スクリーンショットは3回目と同じく描画待ちでタイムアウトした（`file://`のページが静的スナップショット扱い）。HUDは状態値で確かめた

### P01（野望型）視点

- 「塔を高くするか、梁で編むか。どちらもbareに勝ち、シードで勝者が入れ替わる。026の『塔を建てないのが正解』は無くなった」（A3・A4・D2）
- 「迷っても自分の型はほぼ損をしない（遅延3秒 +0.4%）。倒れても積荷の半分は塔が拾う。6秒迷う人の中では一番強い」（E3）
- 不満: 「防具を5Lv積んでも、粘れる揺れの線は30のまま。救助が半分になるだけで、稼ぎは1%しか変わらない」（A2）
- 「平時（迷いなし）では、自分の型は全戦略に負け、bareにも35/80。倒れる遊び方は迷う人の中でしか報われない」

### P02（あき型）視点

- 「黄色の線（注意線30）で帰るのが一番、と画面が言ってくれる。粘った秒数が出るので、迷った分が見える」（C1）
- 「でも3秒迷うと1割以上減って、bareの突撃に負ける。慎重に遊ぶほど、正確に帰ることを求められる」（E3）
- 「倒れないので、踏ん張りも塔の見張りもほとんど見ない（踏ん張り2.1回/ラン）。新しい仕組みは攻める人のためのもの」（A9）

## 判定

**FIX**

理由:

- コアファン仮説「失う物を抱えた積荷と揺れに限れば、防具・塔への投資は救助ありでも価値を持つ」は**塔については成立し、防具については半分**。
  026で全戦略に勝ったbareは、既定で元の7戦略中1〜2つ（ペルソナの型）に44〜47/80の接戦で勝つだけになり、塔を高く／梁で編む2方針が標本で入れ替わる2強になった
- 防具は「救助の回数を半分にする」価値は持ったが、「粘れる揺れの上限」は動かさなかった（027の鎧の成功は、上限の手前に稼ぎの山が無い本命では再現しない）
- 新たに、**合格線が迷いの無い帰還に依存する**ことが分かった（遅延3秒でbareが5戦略に勝つ）。これはシステムを捨てる理由ではなく、
  慎重な遊び方の山の形（T30で鋭く落ちる）の問題。PIVOT/SCRAPは不要

## この要素のシステムとして「本命ゲームに採用すべき部分・捨てる部分」

### 採用すべき部分

1. **救助で失うのは抱えた積荷（鉱石＋撃破の懸賞）と揺れだけ**。お金・装備・時間・ホームは無事。撃破報酬も懸賞として積荷を通す
   （通さないと戦う遊び方には失う物が無い、v1の開発中の観察）。026の支配（54〜72/80）を接戦（44〜47/80）に変えた中心
2. **生存投資を拠点のインフラ（塔の見張り）の下でだけ効かせる**（`armorTower`・`killBonusTower`）。防具を安くしてもbareの支配が戻らない。
   「生存投資の恩恵は投資の幅が一番狭い攻勢に集まる」（v2の学び）への答えで、本命の装備・スキルにも「拠点を整えた人の買い物」として使う
3. **塔の見張りは遠征を見送る**（その遠征で一度でも圏を通れば、どこで倒れても積荷の半分を届ける）。倒れる場所と守る場所のずれを解消した
4. **踏ん張りの受け止め**（踏ん張りが残っていれば、一撃で窓を越える被ダメージをHP1.5割で止めて発動）。凸の被ダメージと組むなら必須
5. **ゲージの2本の線（注意線30・危険線45）と「注意線の外で粘ったN秒」**: 慎重な人と攻める人の山を同じゲージで指し、慎重な人の迷いの損を見える場所に出す
6. **検証の型**: `--preset`で前作の規則を同じコードに残す・投資しない対照群・ボットの帰還線を各戦略の山に揃えてから対比較・
   **対比較を`--delay`ありでも取る**（今回の新規重大は遅延0の表だけでは見えない）

### 捨てる／注意すべき部分

1. **「粘れる上限を上げる」生存投資を、上限の手前で稼ぎが取れるゲームに入れること**: 防具Lv5でも慎重な戦略の最良はT30のまま。
   上限を上げる投資には「上限の向こうにしか無い稼ぎ」が要る
2. **1日1回の踏ん張りの単独効果**: 慎重な戦略は2.1〜10.8回/ラン（weaveは回廊で戻して19回）で、ほとんどが帰り道の保険。合図としての特別さは薄い（027と同じ）
3. **HUDに行を足し続けること**: 13行以上でキャンバスの下半分を覆う。本命では揺れゲージ1本に情報（線・倍率・踏ん張りの点・砂時計）を集約する
4. **遅延0の対比較だけで合格を判定すること**: 正確に帰るボットどうしでは慎重な戦略が勝つが、人の迷いを入れると逆転する

## 次にどのようなゲームを作ればよいか（次サイクルへの具体的提案）

1. **【推奨】029-mining-*: 注意線の向こうにだけある稼ぎ（迷いの罰を慎重な側から外す）**:
   012→…→026（統合）→027（戦闘）→028（統合）の往復パターンに従い、次は単体要素。028の新規重大#1（迷いの罰が慎重な側にだけ掛かる）と中#2（T30の山が鋭い）は、
   027-final提案(2)「粘りの見返りを倍率以外で作る」と同じ根を持つ: 注意線の外には倍率以外に稼ぐ物が無いので、越えた秒数がそのまま損になる。
   採掘単体で次を検証する:
   - 揺れが注意線を越えている間だけ現れ、数秒で消える**質的な獲物**（例: 揺れで割れ目が開き、希少な鉱脈が一時的に露出する）。倍率の上乗せではなく「その時だけ掘れる物」
   - 揺れの凸の被ダメージ（落盤）と、025-tremorveinの揺れのダイヤルはそのまま。防具に相当する投資は「割れ目が開いている時間を延ばす」等、上限の向こうの稼ぎに効く形にする
   - 検証: 対照群（割れ目を無視して注意線で帰る）を置き、`--delay 0/30/60`それぞれの対比較で「慎重な型の3秒の罰が−8%以内」「対照群が過半数で勝つ相手が無い」を合格線に。
     固定閾値の掃引で、投資によって最良の閾値が動くか（028で動かなかったもの）を見る
2. **（次点）029-flagship-*: 028に「割れ目」を直接入れる**: 往復パターンを崩してでも本命で直接試す案。ただし028は9戦略×160シードで1条件約6分かかり、
   単体要素で形を決めてから入れる方が切り分けやすい
3. **【並行・技術】HUDの集約**: 揺れゲージ1本に注意線・危険線・被ダメ倍率・踏ん張りの点・粘った秒数（砂時計）を載せ、文字の行を半分にする。

## Learnings（次の仕様書・次サイクルに持ち越す学び）

- **救助の罰を「抱えた物」に限り、生存投資をインフラ（塔）の下でだけ効かせると、投資しない攻勢の支配は接戦まで崩れる**。
  026のbare 54〜72/80 → 028の44〜47/80（ペルソナの型だけ）。残りは「倒れる型」と「稼ぎの低い型」への僅差
- **上限を上げる投資は、上限の向こうに稼ぎが無いと価値を持たない**。防具Lv5でも慎重な戦略の最良はT30のまま、効いたのは救助の回数（p01 8.6→4.7回）だけ。
  027で鎧が山を動かしたのは、熱を上げ続けないと稼げない（撃破が熱の源）構造だったから
- **救助の罰を軽くすると、迷いの罰は慎重な側に偏る**。倒れる型は迷っても積荷を失うだけ（塔が半分拾う）で−0〜7%、慎重な型は山を越えて−7〜15%。
  遅延3秒でbareの支配が戻り、6秒ではp01が全戦略に勝つ。**合格線の対比較は遅延ありでも取る**
- **慎重な型の損は「救助」でなく「線の外で粘った秒数」として現れる**（wall 24→37→64秒）。これを数える指標（`overCautionTicks`）はHUDと検証の両方に使える
- **大きな検証は条件を先に全部並べて一括で流す**: 15条件×9戦略×160/80シード（15120ラン）を1512ジョブ・20並列で約30分。各ランのJSON行を残せば、
  対比較・掃引・遅延の表はすべて後から同じデータで作れる
