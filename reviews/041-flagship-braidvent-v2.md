## 判定: **FIX**

v1 の重大2つはどちらも向きが直った。**柵の杭**で柵の得がそのまま score に出て（weave −2.7% → +1.5%、荒らし −74%、崩落は柵なし並み）、**弱い b（0.75）**で pusher の大差の一択が「pusher と weave が 0.3% 差で並び、地盤で1位が入れ替わる」形になった（大差の全勝 11/12 → 2/8）。
残るのは (a) 僅差でも全勝の型がいるセルが 7/8、(b) 3秒reset の pusher の大差の全勝、(c) p02 の8位。p02 は b・荒らし・柵のどれにも触れず、v1 の学び「規則が触れる型と、動かしたい型がずれている」が p02 側でも起きている。

## 改善点（3回目で直す、優先度順）

1. **【重大】p02 の8位**: p02 は bare 以外の全員に負ける。v2 の3つの規則はどれも p02 に触れない。候補: (i) p02 のボットが柵を使う（前線拠点の塔2基を梁で編むだけの「小さな柵」を張る＝慎重な型が柵の得を取れるか）、(ii) 拠点で待つ（departHp）間に拠点圏にいるなら荒らしを受けない＝「拠点にいる」ことの価値（今は拠点圏の内外で荒らしは同じ）、(iii) p02 の帰る線（039-final で慎重な型の曲線は平ら）を見直すのはボットの比較として。80シードで p02 の順位と全勝のセル数を並べる
2. **【中】3秒reset で pusher の大差の全勝・weave の罰 −7.1%**: 迷うと梁の作業中に塔が上限を超えた時間が延びる。梁の作業中（G長押しの途中）は自由長の超過で崩れない、または作業の中断で進捗を失わない形を比べる
3. **【中】柵の強さを選べない**: 杭＝梁の耐久で、梁を高く架けるほど固い。柵だけを補強する手（杭を打ち足す）を足すかは、コンテンツの水増しにならない範囲で検討（v3 では保留でもよい）
4. **【軽微・検証】** 全部土・縞・地盤ごとの3秒reset・160シードは未実施。僅差の全勝（差1%未満）を「全勝」と別に数える集計を cells.mjs に足す

## Learnings（次の仕様書・次サイクルに持ち越す学び）

- **「その場にいない時だけ重い」規則は、誰がその場にいないかを先に数える**。拠点圏の外での荒らしは pusher 11.3・p02 11.8 打/ランでほぼ同じ（夜の慎重な型も前線や帰り道にいる）。狙った型だけに効く規則に見えて、実際は全員に掛かった
- **2役の部品は、損の経路を別の耐久に分けると得だけが残る**。柵が梁を叩くと塔が崩れたが、杭（梁とは別の耐久、夜明けに戻る）にすると崩落は柵なし並みで荒らしだけ −74%。「同じ部品の2役」は見た目と置き場所だけ共有し、壊れ方は分ける
- **外した重さは「弱めて戻す」が効く**。b を 0 → 0.75（039 の半分）で、攻める型だけが −1.4〜−4.5%、慎重な型は ±0.5%。039-final の「入れるなら弱めに」は本命でも当たった
- **規則が全員の順位を詰めても、どの規則にも触れない型は置き去りになる**（p02）。崩したい型と、引き上げたい型の両方に触れる規則かを先に確かめる
- 検証の規模: nproc=4 で 9戦略×40シード×1条件が約15分、8ジョブ（2880ラン）が約33分。選定は10シード×8案（約8分）で当たりを付けてから80シードへ
