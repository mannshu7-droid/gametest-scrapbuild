## サイクル39の総括（4回を通じて何を検証したか）

032-finalの提案(1)「早めに引くが次の出撃を強くする（慎重な型を、加点でなく行動が変わる規則で報いる）」を戦闘単体で検証した。
032では「無傷の帰還」の加点が全1440ランで `score − 加点 = 加点なし` と一致し、行動を1つも変えていなかった。
033の答えは**余熱**: 点は足さず、帰り方（育てた熱×残したHP）が次の出撃の始まりの熱（報酬倍率と被ダメージ倍率の両方）を変える。

1. **v1**: 027-emberstake v0.3.0に余熱を1つだけ足した。p02（HP60%で帰る）は補正なしで稼ぎ4位・8勝（余熱なし8位・4勝）、`score − 上乗せ = 余熱なし` の一致0/80。重大は固定線の迷いの崖（p01 3秒 −32%）と刃なしの型
2. **v2**: 熱の盾（踏ん張りの発動で熱の半分を捨て、捨てた熱×0.5の盾に）。3秒 reset で p01 −32 → −4〜6%、6秒 −92 → −25%。遅延0は±4%以内。癒しを持つ型だけ迷い直しが残ると判明
3. **3回目**: 踏ん張りの後の癒しは盾へ。mender 3秒 −34 → −4〜7%、warden −42 → −4〜5%、3秒の sum と reset が全戦略で一致。p02の短い出撃（中#3）は2案を試して不採用
4. **4回目（本レビュー）**: コード無変更のまま、`--grid`（5条件×12戦略＋余熱なし対照）と `--sweepHp`（帰るHP 0.2〜0.7×3条件、シードごとのscore付き）を
   80シード×2組（1〜80・81〜160）で、**既定（v3）と `--tune mendShield=0`（v2相当）の両方**を回した（20プロセス並列、約8分）。ブラウザAIPで3ラン一致と、踏ん張り後の撃破の回復が盾に入る瞬間を確認

  HUD は「HP 16/100 盾11」「踏ん張り中 4.3秒 − 被ダメ半分。今のうちに戻れ」「熱26 報酬×2.04 被ダメ×1.33」、

  同時に、盾は余力に数えないので、この出撃の余熱は0と HUD がはっきり言う
- 浮き文字「熱−N→盾M」は足元、「踏ん張り！戻れ」は頭の上に分かれ、v2の重なり（軽微#6）は解消

### P01（野望型）視点

- **面白かった点**: 熱を育てて粘るほど稼げる（遅延0で p01 11｜10勝の1位圏）一方、踏ん張りで熱の半分を払えば1回は生き延びる。3秒迷っても −3〜5%、6秒でも −10〜13%（v1 −92%）。
  熱が「報酬・被ダメ・保険・次の出撃の始まり」の4役を1本で持ち、どの判断も熱の数字を見ればよい（A9）
- **ストレス**: 上位4つ（even・p01・duel・p02）が1.5%の幅で並び、1位は条件で入れ替わる（遅延0 pusher・迷うと banker）。独走の型が無いのは良いが、「自分の型が強い」と言い切れる場面も無い。
  踏ん張りを使った出撃は余熱がほぼ0になるので、粘る遊び方は余熱の楽しみに触れない（p01 の余熱の平均2.6）

### P02（あき型）視点

- **良い点**: 加点でなく稼ぎそのもので4位・8勝。余熱を外すと3勝なので、「早めに引くと次の出撃が熱24から始まる」が本当に効いている。迷っても3秒 −3%・6秒 −6%で、慎重さがそのまま迷いへの強さになる。
  HUD の「今帰れば次の出撃は熱Nから」で、帰る判断の材料が帰る瞬間に見える（C1）
- **不満**: 出撃は中央値7.3秒・91%が10秒以下のまま。熱を持ち越して出て、少し斬ってすぐ帰る繰り返しになる（B3）。
  迷う条件では banker（もっと細かく出入りする型）の方が強く、「もっと早く帰れ」が正解になる場面がある

## 判定

**FIX**

理由:

- **主仮説（帰り方が次の出撃の始まりを変えれば、早めに引く型が加点なしで稼ぎの中位以上に並ぶ）は成立**。p02 は補正なしで稼ぎ4位・8勝、最良線どうしでも6〜7勝。
  `score − 上乗せ = 余熱なし` の一致は 0/80 ｜ 0/80 で、032の無傷の帰還（1440/1440一致）と違い、**行動が変わる規則**になっている
- 迷いの崖と迷い直しは熱の盾＋癒しは盾へで解消（固定線3秒 −5%以内 12中7｜5、最良線では刃のある非対照の6型すべて）。遅延0の強さはほぼ不変
- 合格線A（bare 0）は刃なしの型で未達、迷う条件の細かい出入りの最適（新規#1）が残る。いずれも本命で「刃なしを作らない」「出入りの代償」で扱える範囲で、PIVOT/SCRAPは不要

## この要素のシステムとして「本命ゲームに採用すべき部分・捨てる部分」

### 採用すべき部分

1. **余熱（奉納時の熱×0.8×余力、余力＝(HP割合−0.2)/0.8）**: 点を足さず、帰り方が次の出撃の始まりを変える。報酬倍率と被ダメージ倍率を一緒に持ち越すので、慎重な型だけが一方的に得をしない。
   **032の「慎重な型は稼ぎで勝てない」への初めての答え**（p02 余熱なし3勝 → 8勝）
2. **熱の盾（踏ん張りの発動の瞬間に熱の半分を捨て、捨てた熱×0.5の盾に換える。1出撃に1度、6秒）**: 迷いの保険を「持っている物を払って生き延びる」にすると、遅延0の強さを変えずに崖だけが消える。
   全部払う（shed=1）は逆効果、盾を厚く（shield=2）すると粘って倒れる型が増える
3. **踏ん張りの後の癒しは盾へ（`mendShield=1`）**: 回復は「帰る理由」を消して迷い直しを生む。HPでなく盾に足せば守りの量は同じまま、帰る理由が画面から消えない（mender −34 → −4〜7%）
4. **HUDの「今帰れば次の出撃は熱Nから」**: 帰る判断の材料を帰る瞬間に出す（032の「今帰れば」の行を、加点でなく次の展開の予告に差し替えた形）
5. **検証の型**: 補正を入れたら**補正なし（`--tune ...=0`）と並べて `score − 上乗せ = 補正なし` の一致数を数える**、迷いの評価は**最良線どうしの総当たり**で見る、修正の効き目は前の版の値（`--tune mendShield=0`）と同じシードで並べる

### 捨てる／注意すべき部分

1. **刃なしの型（tank・warden）**: 撃破が遅く熱が育たないので余熱が無く（平均0.9〜1.0）、最良線どうしでも bare に負ける（027から継承）。
   本命では**刃を初期装備（1段目から持つ）にして、刃なしの型を作らない**（未検証。次サイクルで測る）
2. **余熱の持ち越しを調整する案**（`carryStartFrac`・`carryDmgShare`）: 3回目で不採用。前者は p02 を下げるだけ、後者は慎重な型だけが跳ねる
3. **固定の帰る線での順位づけ**: 迷う条件では sprinter（単調な出入り）を上位に出してしまう。線の遅さを測るだけなので、評価には使わない

## Learnings（次の仕様書・次サイクルに持ち越す学び）

- **慎重な型を報いるには、慎重さを次の行動の資源にする**。余熱は p02 を稼ぎ3勝 → 8勝にし、`score − 上乗せ = 余熱なし` は 0/80（032の加点は 1440/1440 一致）。点でなく「次の出撃の始まり」を変えると行動が変わる
- **持ち越す物には短所も持たせる**。余熱は報酬倍率と一緒に被ダメージ倍率も持ち越すので、慎重な型だけが跳ねない（被ダメを持ち越さない案では banker 5458 → 8642 と跳ねた）
- **持ち越しは「育てた量×残した余裕」に比例させる**と、回数を稼ぐ出入りは最適にならない（遅延0の sprinter は11位）。ただし**迷いの罰が出撃の長さに比例する条件では、細かい出入りが最適に戻る**（6秒で banker 全勝）
- **迷いの保険は「持っている物を払う」形にし、回復は帰る理由を消さない形にする**。熱の盾で崖、癒し→盾で迷い直しが消え、3秒の sum と reset が一致した。いずれも遅延0の強さを±1%しか動かさない
- **保険を使った出撃は、持ち越しも減らす**のが一貫する。盾は余力に数えないので、踏ん張りを使った出撃の余熱はほぼ0。「帰り損ねた人は救うが報いない」
- **修正の効き目は、前の版を `--tune` で再現して同じシードで並べる**。final で v2 相当（`mendShield=0`）を回し、v2レビューの値と一致したうえで差分を読めた
