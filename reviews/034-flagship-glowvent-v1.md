## 今回の検証の問い

033で「慎重な型を、加点でなく次の行動の資源で報いる」答えになった**余熱**を、本命の揺れのダイヤルへ移して同じことが起きるかを見る。
032の**無傷の帰還（score+1.5）は外した**。合格線（routine-state.md）:

1. **加点なしで** p02 が稼ぎ・総当たり（固定線と最良線）で中位以上
2. `score − 上乗せ = 持ち越しなし` の一致が0に近い（＝行動が変わった）
3. bareが過半数で勝つ相手0
4. reset 3秒の罰 −5%以内
5. 遠征の長さの分布、spireAllの全勝が崩れるか

## 実装したもの（v0.1.0）

| 規則 | 内容 |
|---|---|
| 無傷の帰還 | 外した（`soundScore` 1.5→0） |
| **余熱** | 拠点に入った瞬間、直前の揺れ×0.8×余力（(HP割合−0.2)/0.8、0〜1）を覚え、次に**昼の遠征へ出た瞬間の揺れの初期値**にする。救助で0。鉱石を持ち帰った時だけ入れ替わる |
| **揺れの盾** | 踏ん張りの発動で揺れの半分を捨て、捨てた分×0.5の盾（ダメージを先に吸う）に |
| **癒しは盾へ** | その遠征で踏ん張りを使った後は、拠点の外の自然回復を盾に回す |
| HUD | 「今帰れば次は揺れNから」「余熱: 次は揺れNから」「盾N」、揺れゲージに余熱の橙の三角と始まりの揺れの細線 |
| simulate | `--preset 032`、`--lineRel`（帰還線を「この遠征で上げた分」で測る、既定1）、`--hp 戦略=割合`、要約に `carry`・`shield`・`tripSec` |

揺れは報酬（鉱石と懸賞の揺れボーナス）と危険（凸の被ダメージ・落盤・帰着線）を1本で持つので、**揺れそのものを持ち越せば倍率と危険の両方を持ち越せる**（033 Learnings「持ち越す物には短所も持たせる」）。

### 開発中の観察（20シード）

- 初版は「拠点に入るたびに余熱が入れ替わる」だった。ボットは拠点の縁の敵を斬るために1ランに約1000回の短い出入り（懸賞だけの帰還）をし、
  そのたびに余熱が冷めて**始まりの揺れの平均は0.4**。「鉱石を持ち帰った時だけ入れ替わる（それ以外は覚えたまま）」にして平均9〜12（p02 11.7）
- 遠征の長さも同じ理由で「鉱石を持ち帰った遠征」だけを数える（全部数えると中央値0.1秒）
- 帰還線を絶対値で測る（`--lineRel 0`）と、多くの戦略で相対（既定）より高い（spireAll 4470→4598、weave 4481→4603）。線の測り方の比較は下の(5)

### (6) 遠征の長さと spireAll（合格線5）

- 余熱で**全戦略の遠征が短くなった**（中央値 spireAll 29.3→24.7秒、weave 25.6→22.4、p02 19.9→17.5、10秒未満 0.07〜0.18 → 0.10〜0.24）。
  始まりの揺れが高い分、帰着線に早く届く（相対線でも落盤と被ダメージで早く帰る）。**迷う条件で細かい出入りが最適に寄る**（033-final 新規#1）兆しは、遅延0の時点で出ている
- spireAllは既定の帰還線では遅延0で7｜8勝（032は8｜8全勝）、weaveが8｜7勝で並んだ。ただし**最良線どうしではspireAllが8｜8の全勝に戻る**（(5)）。全勝は崩れていない

## 定性評価（ブラウザAIP実プレイ）

- 単一HTML（`node tools/single-html.mjs`）に `npx esbuild headless/simulate.ts --bundle --format=iife --global-name=__BOTLIB__` を埋め込み、ブラウザペインで開いて `window.__AIP__` からボットを動かした。3/3でヘッドレスと完全一致
- p02×501を、余熱8で始めた遠征（tick 4409、x50、揺れ16、HP93/200）で止めてHUDを確認: 1行目に「**今帰れば次は揺れ4から**」、ゲージの下に橙の三角。
  **始めた時の8より少ない4しか持ち越せない**のが一目で分かる（余力＝(0.465−0.2)/0.8＝0.33）。HPで帰るp02は毎回余熱を半分に減らして帰っている
- 人が見ると「今帰れば次はN」は032の「今帰れば無傷+1.5点」より判断の材料になる（数字が次の遠征の始まりを指す）。ただしNが4〜15と小さく、ゲージの上では注意線30の手前の小さな三角で、目立たない

### P01（野望型）視点

- 攻勢（p01・bare）には余熱が損（稼ぎ−3〜−7%）: 危険線まで粘って帰ると余力が小さく、たまに大きな余熱を持って出ると落盤（2.1→4.7回）と救助（5.4→7.7回）が増える。
  「持ち越す物に短所がある」は攻勢には効いている
- 揺れの盾は p01 だけが使う（吸収101/ラン）が、罰の差はほぼ無い。盾の量（7〜20）がHP200の体に対して小さい
- 1位争いがweaveとspireAllの塔の型で、攻勢が届かないのは032と同じ

### P02（あき型）視点

- **自分の型（HP45%で引く）はまた下位**（1勝、稼ぎ8位）。早めに引くほど余熱は増えるが、それ以上に遠征が短くなって稼ぎが減る（帰るHPの掃引）。
  「残して帰ると次が楽になる」手応えは、数字（揺れ+5）としては見えるが稼ぎにならない
- 加点が無くなったので、032の「点だけ上がる」違和感は消えた。順位は正直になったが、慎重さはまだ報われない

## 判定

**FIX**。余熱は全ランで行動を変え（0/1440一致）、攻勢には短所として効いた。統合の土台（032の全規則・`--preset 032`で完全一致）は健全。
最良線ではreset 3秒の罰が全戦略−5%以内、余熱で塔の型の最良線がT45→T30へ下がった（揺れで見れば「早めに帰る」が得になった）。
ただし主目的の「慎重な型を稼ぎで報いる」は未達（重大#1）、揺れの盾は空振り（重大#2）。どちらも規則の大きさの問題で、規則の形（揺れを持ち越す）は捨てずに直す。

## 2回目（FIX+REVIEW）でやること（優先順）

1. **重大#1**: 余熱を「余力を残す理由」になる大きさにする。候補を同じシードで比べる:
   (a) 持ち越した分の揺れボーナスを割れ目の売値にも乗せる（稼ぎの3割に効く）、(b) 余熱の倍率を上げる（carryFrac 0.8 → 1.2〜1.5、揺れ30で帰れば次は36〜45から）、
   (c) 余力の床を上げる（carryFloor 0.2 → 0.4、HPを残した時だけ持ち越す）。合格線は帰るHPの山がp02で上へ動くこと、p02が中位（4勝以上）
2. **重大#2**: 盾を揺れでなくHPの割合で作る（例: 捨てた揺れ×最大HPの1%）か、盾を外して踏ん張りを032のまま残す。休み＝帰還の宣言との重なりは、盾なしの方が罰が小さいので「外す」を第一候補に
3. 中#3・#4: 迷った遠征（帰着線が帰還線を越えてから帰った遠征）は余熱を持ち越さない、を試す（033の「保険を使った出撃は持ち越しも減らす」を迷いにも広げる）
4. 中#5: 余熱の表示を、拠点の入口で大きく出す

## Learnings（次の回・次サイクルに持ち越す学び）

- **持ち越しの効き目は、持ち越すダイヤルが報酬のどれだけに掛かっているかで決まる**。033の熱は報酬の全部の倍率、034の揺れボーナスは鉱石と塔の下の懸賞だけ（割れ目＝稼ぎの3割は対象外）で上乗せは稼ぎの2%。同じ規則を移すなら、掛かる範囲を先に測る
- **行動が変わったことと、狙った行動に変わったことは別**。0/1440一致で行動は変わり、揺れの帰還線の山はT45→T30へ下がったが、p02の帰るHPの山は動かなかった。一致数の次に「最適な帰るHP・線のどちらが動いたか」を掃引で見る
- **危険を一緒に持ち越すと、もともと危険の高い型に損が集まる**（p01 −3%、bare −7%、落盤×2〜3）。攻勢の抑えとしては働く
- **保険の大きさは体の大きさに合わせる**。揺れの盾は「捨てた揺れ×0.5」で、HP100の033では効き、HP200前後で揺れ30の034では0〜4しか吸わなかった
- **出入りの多いボットでは、持ち越しは「何をした時に入れ替わるか」を決めないと薄まる**。拠点の縁の出入り約1000回/ランで余熱が0.4まで冷めた。「鉱石を持ち帰った時だけ」で9〜12に戻った
