## v1からの変更

| v1の指摘 | 対応 |
|---|---|
| **重大#1** 反応遅延の崖（reset 3秒の固定線で p01 −32〜35%、6秒 −91%） | **熱の盾**を追加: 踏ん張り（HP3割で1出撃に1度）の発動の瞬間に熱の半分を捨て、捨てた熱1につき0.5の盾（HPより先にダメージを吸う、奉納・救助まで残る）に換える。踏ん張りの長さを3秒→6秒に。`graceShed=0.5`・`graceShield=0.5`・`graceTicks=60` |
| **重大#2** bareが過半数で勝つ相手 | 合格線Aの対象を決めた: **対照（noshop・sprinter）は外す**。残る tank・warden（刃なし）は027から継承した弱さとして測定のみ（下の(4)） |
| 中#3 遅延時に sprinter が1〜2位 | #1の修正後に再測定（下の(3)）。固定線では残り、最良線では消えた |
| 中#4 p02 の出撃が短い（91%が10秒以下） | 未対応（v3へ） |
| 中#5 ボットの既定の帰る線が最良より遅い | 既定線は変えず、**最良線どうしの総当たり**を新たに測った（下の(5)） |
| 軽微#6 sum と reset の差が無い | 5条件を「遅延0／1秒reset／3秒sum／3秒reset／6秒reset」に変更（6秒sumを外し1秒を足した） |

熱の盾の考え方: v1の余熱は「早く帰った人」だけを報い、「帰り損ねた人」を救う手が無かった。被ダメージ倍率は熱に対して凸なので、熱を半分にすると被ダメージは大きく下がる（熱70: ×3.4 → 熱35: ×1.6）。
代わりに帰り道の撃破の報酬倍率と余熱の見込みが下がる。HP3割より上で帰る型は発動しないので、遅延0の強さは変わりにくいはず、という狙い。

試した値（20シード、p01 遅延3秒）: 盾なし 3960 → `shed0.5/shield0.5` 5397 → ＋踏ん張り6秒 5586。`shed=1`（熱を全部捨てる）は 4874 で、帰り道の報酬が減りすぎて逆効果。`shield=2` は刃なしの型が悪化（盾があると粘って倒れる）。
6秒迷いでは踏ん張りの長さが効き（p01 盾だけ 2771 → ＋6秒 4325）、6秒を採った。

### P01（野望型）視点

- **面白かった点**: 熱を上げて粘り、3割を切った瞬間に「熱を半分払って生き延びる」かどうかが決まる。崖が「1回は払える保険」になり、攻めても全部は失わない（3秒迷い −32% → −4〜6%）。
  遅延0の強さは変わらない（p01 −1%）ので、上手い人の遊び方は奪っていない
- **ストレス**: 6秒迷うと −25%。盾は1出撃に1度なので、2度目の迷いは救われない。even（4種均等）が遅延0で11勝の1位になり、p01 の独走感は減った（上位4つが3%）

### P02（あき型）視点

- **良い点**: 自分の型（HP60%で帰る）は盾をほぼ使わない（1ランに60の熱）。v1の報い（稼ぎ4位・8勝・余熱なしとの一致0/80）はそのまま。
  6秒迷っても −5% で、慎重さが迷いへの強さにもなっている。「早く帰るほど迷いに強く、迷っても1回は助かる」が説明しやすい
- **不満**: 出撃の91%が10秒以下（中央値7.3秒）は v1 と同じ（中#4未対応）。癒しを積むと迷い直しで−32%（mender）、刃なしは余熱が育たない

## 判定

**FIX**

- v1の重大#1（迷いの崖）は解消: 3秒 reset の固定線で攻める型は p01 −4〜6%・duel −2〜3%（v1 −32〜36%）、6秒は p01 −25%（v1 −92%）。最良線の罰は刃のある非対照の6型で3秒−5%以内、6秒でも−5〜7%
- 遅延0の強さはほぼ不変（−1.2〜+3.9%）、v1の主結果（p02 稼ぎ4位・8勝、一致0/80）も不変
- v1の重大#2は対象を決めて測定: 対照を除くと bare が勝つのは刃なし2つ＋固定線の pusher・mender。最良線の6秒では0
- 残りは癒しの迷い直し・刃なし・p02の短い出撃（いずれも中）

## Learnings

- **迷いの保険は「持っている物を払って生き延びる」にすると、遅延0の強さを変えない**。熱の盾は遅延0でほぼ毎出撃発動しても score は±4%以内、3秒の迷いは −32% → −4〜6%。上手い人は払う前に帰っているか、払っても帰り道の報酬が小さい
- **凸の短所を持つダイヤルは、半分払うだけで大きく軽くなる**。熱70→35で被ダメ ×3.4 → ×1.6。全部払う（shed=1）は帰り道の報酬が減りすぎて逆効果（p01 4874 < 5397）
- **保険は1回に絞り、帰らないことは救わない**。帰る線が踏ん張りより下の型（pusher・tank）は救われず、HP0.2の線の崖も残る。早めに引く理由は消えていない（最良線は迷うと70%のまま）
- **戦闘でも癒しを持つ型だけは sum と reset が分かれる**（mender 3秒 sum −12% / reset −33%）。回復は「帰る理由」を消すので、迷い直しを生む
- **固定線の順位は「線の遅さ」を測ってしまう**。遅延時の sprinter の上位は、最良線どうしでは消えた（2〜7勝）。迷いの評価は最良線どうしの総当たりで見る
