## コアファン仮説（1行）

> 昼の遠征を燃料（帰れる／帰れない）から揺れ（粘るほど売値が上がり落盤しやすい）に置き換えると、遠征の判断が崖ではなく
> 連続的なリスクの調整になり、梁で編んだ塔の回廊が「揺れが下がる踊り場」として塔を建てる理由に加わるはず。

## コンセプト

- ジャンル / 視点: 2D横スクロール（上から見たレーン帯）、戦闘×採掘×建築＋昼夜サイクル防衛（本命ゲーム統合フェーズ・第十一世代）
- プレイ時間の想定: 1セッション20〜35分（20000tick、10tick/秒）。024と同一
- 参考にするゲーム: 024-flagship-spirelace（ベース。全システムを継承）、025-mining-tremorvein（揺れ・落盤・救助の移植元）

## コアループ

024と同じ（昼に採掘・前進して稼ぐ→拠点で強化・タレット設置・塔の積み増しと梁→夜にレイダーを防衛）。変わるのは昼の遠征の制約:

- 拠点の外にいる間、**揺れ**がたまる（拠点から遠いほど速く、掘っている間は1.5倍）。拠点に入ると0に戻る
- 揺れが高いほど、その瞬間に掘った鉱石の**売値が上がる**（揺れ100で+60%）＝粘る理由
- 揺れが20を超えると毎tick**落盤**しうる（揺れ−20、HP−、積荷の1/3を落とす部分損失）＝粘る危険
- **HP0は即死ではなく救助**（ホームへ運ばれ、積荷全損＋所持金の15%＋60tickの手当て）。敗北はホーム陥落だけ
- **梁で編んだ塔の回廊（woven）は足場**: 中で掘らずにいる間は揺れが毎tick1.5下がる（掘っている間は0.5倍でたまる）。
  梁なしの塔のレーン（lane）は揺れのたまる速さ0.65倍。燃料版の「回廊は燃料0.5倍・圏内0.65倍」の読み替え
- **夕暮れ**（夜の予告nightWarning中）に積荷を抱えて拠点の外にいると、揺れのたまる速さ×1.5（025の核石×3の翻案、低めから）

## システム仕様

024の全システムを継承し、`resource`（'tremor'既定／'fuel'）で燃料版（024と完全一致の対照群）に切り替えられる。
`new Game(seed, 'fuel')`、simulateの`--resource fuel`、ブラウザの`?resource=fuel`。

### 揺れ（resource='tremor'）

| 項目 | 式・値 |
|---|---|
| たまる速さ | `0.08 + 0.4×(d/40)²`/tick（dは最寄りの拠点からのx距離）× 掘削1.5 × 支保・ランタン × 回廊/圏 × 夕暮れ |
| 上限 | 150 |
| 売値ボーナス | 掘った瞬間の揺れで `min(T,100)/100 × 0.6` |
| 落盤率 | T<20で0、以上で `0.00035×((T−20)/10)²`/tick（025と同じ） |
| 落盤 | HP−(12+d×0.3)×危険耐性、積荷の1/3（価値は按分）、揺れ−20 |
| 毒ガス | 揺れ+15（燃料版は燃料−15） |
| 救助 | ホームへ、積荷全損、所持金の15%、HP全快、60tick行動不能 |
| テレポート | 解禁済みならいつでも、積荷の価値の1/4を失う（燃料版は燃料25） |
| 支保（brace、燃料タンクの置き換え） | 揺れのたまる速さ−10%/Lv（下限0.4倍）、6Lv、価格は燃料タンクと同じ（20×1.4^Lv） |
| ランタン | 燃料版と同じく受動の消費（＝揺れ）−5%/Lv |
| 帰着線 `estTremorAtReturn` | 今のレーンをホーム方向へ歩いて最寄りの拠点圏に入るまでに**揺れが最も高くなる値**（回廊に入ると下がるので回廊の手前がピーク） |
| miningRiskLevel | 帰着線≥60でdanger、≥40でcaution（燃料版は燃料マージン） |
| returnRiskLevel（夜） | 燃料マージンの代わりに帰着線（≥60＝余裕1.2倍未満相当、≥40＝2.0倍未満相当）＋帰路のレイダー数 |

## タッチ操作の想定（iPad/Android、Capacitor移植時）

- 移動・攻撃・ダッシュ・建設・塔の操作は024と同じ（仮想スティック＋アクションボタン、塔パネルの長押し）
- 揺れゲージは画面上端に横長で常時表示し、帰着線が危険線に近づくとゲージ全体が脈打つ（振動フィードバックも併用）。
  タップで「売値+%・落盤率・帰着の見積もり」の吹き出しを開く。数字を読まなくても「白い線が赤い線に届いたら帰る」で遊べる
- 回廊（足場）の中にいる間は、ゲージの横に下向き矢印を出し、地面のタイルを淡く光らせる（立ち止まると揺れが下がると分かる）
- 救助の手当て中は、画面中央に残り秒数の輪を出し、入力を受け付けないことを明示する
- 5キー（支保）は拠点ショップの一覧から購入（燃料タンクの位置に置き換え）

## AI評価の観点

- **燃料版と揺れ版の対比較**（同じ戦略・同じシード、同点を分ける）。燃料版は024と完全一致すること（無回帰）
- **崖か連続か**: 同じボットの帰還判断を固定閾値にして掃引する（`--returnAt`）。燃料版は「燃料≤帰還推定燃料＋N」、揺れ版は「帰着線≥N」
- **条件が行動を変えたシード数**: 回廊で揺れが下がったtickがあるシード、夕暮れtickがあるシード、救助のあったシードを先に数える
- 024の3方針（spire・spireAll・weave）が揺れ版でも互いを支配しないか
- 救助が死の代わりとして重すぎ／軽すぎないか（救助費・失った積荷・救助の内訳）
- ボットに無い「迷う時間」: ブラウザで遠征中にボットを止めて`wait`を送り、何秒で落盤・救助になるかを測る
