- 土台: [033-combat-spareglow](../033-combat-spareglow/spec.md) v0.3.0（熱のダイヤル・奉納・救助・踏ん張り・余熱・熱の盾・癒しは盾へ）をそのまま使い、**大振りの予兆**の規則を1つだけ足す
- 要素: **戦闘（combat）単体**（採掘・建築は入れない）

## コアファン仮説（1行）

> このゲームは「重兵の大振りは予兆が見えるので、読んで一歩引けば空振りになる」ので、
> 被ダメを**腕で**減らせる。HPを残して早く帰る型は、避けるほど遠征が長くなり熱が育つ＝**慎重さが「長く戦える」に変わる**はず。

## 036からの引き継ぎと、この仕様で答える問い

- 036-final: 本命の p02（HP45%で帰る型）は20セル中17で8位。遠征の終わりは 98.5/ラン が HP、被ダメは9戦略で最大。
  帰るHPを0.3に下げると上がる＝**8位は規則でなく戦い方側（HPの減る速さ）**
- 034（余熱）・035/036（坑道）は「慎重な型を揺れ・地形で報いる」規則で、HPの減りには触れなかった
- この仕様の答え: **被ダメの速さが「読み」で変わる**規則を1つだけ足す。避けた回数に点は付けない（加点しない）。
  避けた結果はHPが残る（遠征が延びる）ことと、空振りの隙への一撃で熱が少し上がること（熱は報酬と被ダメの両方を上げる1本のダイヤル）だけ
- 検証で答える問い（routine-state.md の合格線）:
  1. **HPで早く帰る型（p02）が加点なしで稼ぎ中位以上**（12戦略中6位以内）
  2. **帰るHPの最良が 0.3 より上へ動く**（p02 の帰るHPの掃引 0.2〜0.7）
  3. bare（避けない・防具なし）が過半数で勝つ相手 0
  4. reset 3秒の罰 −5%以内（予兆なしの対照と同じシード、5条件×4組）
  5. 要約表に **被ダメ/秒・HPで帰った遠征数** を入れる（036で効いた指標）

## コンセプト

- ジャンル: 見下ろし2Dのアリーナ近接戦闘（ホード系）。円形の闘技場の中央に篝火（027/033と同じ）
- 1セッション: 10分（6000tick、10tps）で「夜明け」。スコアは累計奉納
- 参考: アクションゲームの「予兆→回避→反撃」（ソウルライクの大振り、Hadesの赤い攻撃範囲表示）を、ホードの群れの中の1体にだけ置く

## コアループ

1. 篝火から出て、湧き続ける敵を斬る。撃破ごとに残り火を拾い、熱が上がる（報酬 ×(1+熱/25)、被ダメ ×(1+(熱/45)²)）
2. **重兵は手が届くと足を止めて0.8秒振りかぶる**（赤い円＝当たる範囲、輪が閉じたら打つ）。打つ瞬間に赤い円の外にいるか、ダッシュの無敵中なら**空振り**
3. 空振りした重兵は0.6秒動かず打たない（隙）。**隙への最初の一撃は熱+3**（点は足さない）
4. 雑兵・走り屋は033と同じ（手が届いた瞬間に打つ。予兆なし）
5. 篝火の中央で1.5秒の詠唱＝奉納: 残り火を確定、HP全快、余熱を持ち越す（033と同じ）
6. HP0 → 救助: 抱えた残り火と熱を全て失う（033と同じ）

## システム仕様

### ワールド・敵・ショップ・余熱・踏ん張り

033-combat-spareglow v0.3.0 と同じ（半径11の闘技場、篝火の上では斬れない、火を恐れる半径4、雑兵・走り屋・重兵、時間で強化、
多芸は高くつく、余熱 `熱×0.8×余力`、踏ん張り＋熱の盾、踏ん張りの後の癒しは盾へ）。詳細は [033の仕様書](../033-combat-spareglow/spec.md)。

### 037で足すもの: 大振りの予兆（telegraph）

| 項目 | 値 | 意味 |
|---|---|---|
| `windupBrute` | 8 | 重兵の振りかぶりの長さ（tick）。この間は足を止める |
| `windupGrunt` / `windupRunner` | 0 / 0 | 雑兵・走り屋は予兆なし（033と同じ）。読める敵を1種に絞る |
| `windupScale` | 1 | 全体の倍率。**0で033と同じ規則（対照）** |
| `strikeSlack` | 0.5 | 打つ瞬間に「手の長さ＋これ」より外なら空振り（重兵 1.1+0.5=1.6。斬る半径1.5より少し広い＝避けると一度は手が届かなくなる） |
| `whiffStun` | 6 | 空振りの後の隙（tick）。動かず打たない |
| `punishHeat` | 3 | 隙への最初の一撃で熱+3（撃破の熱は雑兵5・重兵10）。0で「避けるだけ」の対照 |

- 避ける一歩を踏むtickは斬れない（1tickに1行動）。避けは攻撃の手数と引き換え
- 予兆の間に倒せば打たれない（斬って止める読みもある）
- ダッシュの無敵（4tick）でも空振りになる（027からある無敵の使いみちが増える）
- HUD: 予兆中の重兵に赤い円（当たる範囲）と閉じていく輪、頭上に「!」。空振りで「空振り」の浮き文字、隙の重兵に黄色い輪と「隙」。
  右下に「空振り N回｜被弾 N回｜隙への一撃 N回（熱+3）」
- 指標（simulate）: 被ダメ/秒（`dmgPerSec`）、被弾回数（`hitsTaken`）、空振らせた回数（`whiffs`）、隙への一撃（`punishes`）、
  **HPで帰った回数／熱で帰った回数**（`hpReturns`/`heatReturns`、ボットが帰ると決めた理由）

### ボットの読み（037で追加）

- 予兆が**見えてから `readLag`=3tick（0.3秒）後**に反応する（人の反応時間）。`--readLag N` で変えられる
- 当たる位置にいる予兆について、4方向それぞれ「残りtickで赤い円の外へ出られる予兆の重み（攻撃力）」が最大の向きへ一歩引く。外へ出られない予兆は無視して斬り合う
- 斬れば全部倒せる予兆は斬って止める
- **bare は読まない**（避けない・防具なし＝合格線の対照）。他の11戦略は読む。`--noRead` で全戦略が読まない（規則はそのまま）
- 帰る判断・強化の順・帰るHPの線は033と同じ（p02 は熱+40かHP60%）

| 戦略 | 強化の順 | 帰る熱の増分 | 帰るHP | 読む |
|---|---|---|---|---|
| p01 | 刃・鎧・刃・癒し・鎧・器 | +100 | 35% | ○ |
| **p02** | 器・鎧・癒し・刃 | +40 | **60%** | ○ |
| bare | 刃のみ | +60 | 30% | **×（対照）** |
| noshop / tank / mender / even / duel / warden / banker / pusher / sprinter | 033と同じ | | | ○ |

## タッチ操作の想定（iPad/Android、Capacitor移植時）

- 左下の仮想スティック: 移動。**予兆（赤い円）を見たら、スティックを敵と逆へ弾くと一歩引く**（専用ボタンは足さない。避けは移動そのもの）
- 右下の大ボタン: 斬る（押しっぱなしで連続）。大ボタンを外側へスワイプ: ダッシュ（無敵中の大振りも空振り）
- 赤い円は指で隠れにくいよう、敵の真下でなく**画面の地面に大きく**描く（半径1.6タイル）。輪が閉じる速さで残り時間を読む
- 篝火の上では大ボタンが「奉納」（長押し1.5秒）、画面右に強化パネル（033と同じ）
- 実装はキーボード（WASD・Space・Shift・B長押し・1〜4）。core は触らない

## バランス初期値

033 v0.3.0 の TUNE をそのまま使い、`windupBrute=8`・`strikeSlack=0.5`・`whiffStun=6`・`punishHeat=3` を足した。
`--tune windupScale=0` で 033 と完全に同じ規則（全戦略・全シードで score 一致を確認）。

v1 の調整の経緯（20シード、遅延0）:
- 全種に予兆（雑兵6・走り屋5・重兵9tick、`strikeSlack 0.2`、`whiffStun 12`）: 読む型の score がほぼ2倍（p01 5743→10496）、熱100で過ごす時間が70→520秒。
  読めば被ダメがほぼ消え、熱のダイヤルの短所が無くなった → **予兆は重兵だけ**
- 重兵だけ・`strikeSlack 0.2`・`whiffStun 12`: まだ p01 +74%（空振らせた重兵は隙のあとすぐ次の予兆に入り、ずっと無害）→ **`strikeSlack 0.5`・`whiffStun 6`**（避けに2〜3歩かかり、隙は短い）
- この値で読む型 +25〜40%（読まない場合比）。予兆の規則だけ（誰も読まない）でも重兵が足を止める分 +5〜10%

## AI評価の観点

- 予兆なし（`windupScale=0`）と並べ、p02 の順位・被ダメ/秒・HPで帰った回数・遠征の長さがどう動くか
- 帰るHPの最良（掃引 0.2〜0.7）が予兆なしより上へ動くか
- 読む／読まない（`--noRead`）、隙の熱なし（`punishHeat=0`）、反応0.6秒（`--readLag 6`）の対照で、何が効いているかを分ける
- bare（読まない）が過半数で勝つ相手。reset 3秒・6秒の罰
