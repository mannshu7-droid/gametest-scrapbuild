## コアファン仮説（1行）

> 地盤が「単独で立てる高さ」を決め、敵の来る向きが「守る辺の数」を決める。**固い地盤で一方向なら梁なしの塔を来る側から、柔らかい地盤や全周なら梁で編んだ高い塔**——
> 条件を見て塔と梁の配分を変えることが勝ち筋になり、どれか1つの型が全条件で勝つことはない。

## コンセプト

- ジャンル / 視点: 真上から見た拠点防衛の**建築単体**。戦闘操作は無い（塔が自動で撃つ）。プレイヤーは歩いて台座へ行き、塔を積む・梁を架けるだけ
- プレイ時間の想定: 1セッション10分（6000tick、10tick/秒。昼50秒・夜50秒×6日）
- 参考にするゲーム: 024-flagship-spirelace（自由長と梁）、023-building-rootweave（梁で天井を越える）、031-building-propway（建築単体の検証の型）

## コアループ

1. 昼: 拠点を囲む8つの台座を歩いて回り、塔を1段ずつ積む（費用＋2秒）。隣の台座どうしが同じくらいの高さなら梁を架ける（費用＋3秒）
2. 夜: 敵が条件の向きから来る。塔は射程内の敵を自動で撃つ（拠点に一番近い敵から）。**歩兵**は拠点へ歩き、梁にぶつかると止まって梁を叩く。**射手**は拠点から7マスで止まって撃つ（近くに梁があれば梁を、無ければ拠点を）
3. 夜の途中で1回、突風が吹く。自由長の上限を超えた塔は上の段が折れうる
4. 撃破で報酬、歩兵が拠点に着くと −15（v0.1.0 は −10）、射手の矢1発 −1。夜明けに残った敵は逃げる
5. 稼いだお金でまた積む／梁を架ける／壊れかけの梁を架け直す（修理）

## システム仕様

調整値は `TUNE`（src/core/game.ts）にまとめ、`--tune key=value` で上書きできる。

### ワールド

| 項目 | 値 |
|---|---|
| 盤面 | 17×17マス、拠点は中央 (8,8) |
| 台座 | 拠点から3マスの正方形の角と辺の中点の8つ（時計回りに 1〜8、隣どうしは3マス）。8本の辺が拠点を囲む輪になる |
| 条件（敵の向き） | `one`＝北だけ（±0.6rad）、`two`＝北と南を交互、`ring`＝全周。出現は拠点から9.5マス |
| 条件（地盤） | 自由長の上限 `rock`＝5段、`soil`＝4段、`marsh`＝3段 |
| 既定の条件 | 指定が無ければシードで決まる（向き＝seed%3、地盤＝⌊seed/3⌋%3）。`?seed=N` で変わる |

### プレイヤー

- 1マス移動（移動の後1tickは動けない）。台座のチェビシェフ1以内で作業できる
- **積む**: 隣の台座の塔を1段。費用 10＋3×新しい高さ、2秒（作業中は動けない）。最高12段
- **梁**: 隣の台座から輪の隣（時計回り／反時計回り）へ。高さ＝2塔の低い方、費用 15＋3×高さ、3秒。今より高い時か、耐久が減っている時（修理）だけ架けられる

### 塔・自由長・梁（このゲームの主題）

| 項目 | 式・値 | TUNE |
|---|---|---|
| 射程 | 1.5＋0.9×高さ（h4 で 5.1、h8 で 8.7） | `rangeBase`・`rangePerH` |
| 撃つ間隔 | 1秒に1発、1ダメージ。拠点自身も射程2.5で撃つ | `fireTicks`・`baseRange` |
| 自由長 | 高さ − その塔に架かる最高の梁の高さ | — |
| 上限超え | 自由長 − 地盤の上限（>0 で赤） | `slenderRock/Soil/Marsh` |
| 突風 | 夜に1回、強さ0.6〜1.4。上限を超えた塔は確率 min(1, 1.0×超え×強さ)（v0.1.0 は 0.35） で「梁の高さ＋上限」まで折れる | `gustK`・`gustMin/Max` |
| 梁の耐久 | 20＋5×高さ。歩兵は1秒に1、射手は2秒に1（梁の中点から3マス以内） | `beamHpBase/PerH`・`beamHitTicks`・`archerBeamReach` |
| 梁が落ちた時 | 両塔の自由長が伸び、上限を超えれば強さ1でその場で折れうる | — |

### 敵

| 種類 | 行動 | HP |
|---|---|---|
| 歩兵（8.5割） | 拠点へまっすぐ歩く（0.8マス/秒）。梁を横切れない（止まって叩く）。拠点に着くと −15 で消える | 4＋2×(夜−1) |
| 射手（1.5割、v0.1.0 は3割） | 拠点から7マスで止まり、2秒に1発。梁の中点が3マス以内なら梁を、無ければ拠点を撃つ（−1） | 同じ |

- 夜 n の数: 10＋4×(n−1)（計120体）。出現は夜の最初の30秒に散らす。出現の位置・種類・突風の時刻はシードで決まり、戦略に依らない（同じシードなら全戦略が同じ敵を相手にする）

### 経済

| 収入 | 使い道 |
|---|---|
| 初期50、毎秒1、撃破1体5 | 塔を積む・梁を架ける・梁の修理 |

### 勝利/敗北条件・スコア

- 6日（6000tick）で終わり。死は無い
- **スコア＝守りの稼ぎ＝撃破報酬 − 荒らされた額（歩兵10・矢1）**。所持金の残りは数えない（お金は建てるためのもの。031 の「建築費をスコアから引く」とは違い、同じお金をどの形に変えるかを比べる）
- 所持金は荒らされるとマイナスになりうる（借り。マイナスの間は建てられない）

## バランス初期値（v0.1.0、検証ボットの戦略）

F＝敵が来る側の台座（one: 北の3つ、two: 北と南の6つ、ring: 8つ）、E＝来る側の辺、L＝地盤の上限。ボットは計画の順に、払えるようになったら作業する。梁の耐久が半分（p02 は7割）を切ったら架け直す。

| 戦略 | 計画 |
|---|---|
| p01（野望型） | 来る側の真ん中（one: 2、two: 2と6、ring: 2・4・6・8）の両隣と真ん中を L →両隣と梁 → 真ん中を 2L → 残りを L → 両隣を 2L → 梁 → 真ん中を12 |
| p02（あき型） | 全部を L−1（折れない）→ 来る側に梁 → 来る側を 2(L−1) → 梁 → … |
| weave | 来る側を L → 梁 → 2L → 梁 → 12 |
| weaveAll | 全部を L → 全周に梁 → 2L → 梁 → 12 |
| wall | 全部を2 → 全周に梁（安い輪）→ 全部を 2+L → 梁 → 12 |
| spireAll | 全部を一斉に L まで（梁なし、そこで止まる） |
| spire | 来る側を L → 残りを L（梁なし） |
| tall | 全部を L+2（梁なし、上限を超える。折れたら積み直す） |
| bare（対照） | 何も建てない |

## AI評価の観点

- **合格線（routine-state.md）**: 全勝の型（他の8戦略すべてに80シード中の過半数で勝つ）がいるセルが9中4以下、bare が過半数で勝つ相手0、80シード×2組で1位と全勝が揺れないこと
- 1位が条件で入れ替わるか（梁で編む型が勝つセルと、梁なしが勝つセルが両方あるか）
- 梁が「壁」として働いているか（止めた歩兵・荒らしの数）、射手の矢が梁に吸われているか
- 上限を超える型（tall）が折れの罰で損をしているか
- スコアの内訳（撃破・荒らし・矢）で、何が順位を決めているか
