## コアファン仮説（1行）

> 「掘る（採掘＝生産行動）ほど掘削音で敵を呼び込み、その敵と戦う（戦闘＝消費行動）ために稼いだ資源で
> 両カテゴリを強化しないと徐々に押し戻される」という、採掘と戦闘が互いを駆動し合う一体化ループが、
> 単体の採掘・単体の戦闘にはない緊張と面白さを生むはず。

## コンセプト

- ジャンル / 視点: 縦シャフト採掘 + リアルタイム近接戦闘（2Dトップダウン、003と同じ縦シャフト視点）
- プレイ時間の想定: 1セッション10〜20分（往復を複数回繰り返す想定。003のB3知見を踏襲）
- 参考にするゲーム: 7 Days to Die（採掘と戦闘の併存）、Deep Rock Galactic（掘削音が敵を呼ぶ緊張感）、
  および本リポジトリの002-combat-ironring・003-mining-deepvein

## コアループ

```
地上(常設ショップ)で採掘・戦闘カテゴリを強化
  → 坑道を掘り進む（鉱石獲得、同時に掘削音が蓄積し敵の湧きを誘発）
  → 敵と接敵したら戦闘（倒すか、被弾を抑えて離脱）
  → 燃料(松明)が尽きる前・HPが危険域に入る前に地上へ帰還
  → 鉱石を売却し、稼いだ金で採掘/戦闘/共通カテゴリを強化
  → さらに深く、より稼げるが敵も強い層へ再挑戦（深さに理論上の上限はなく、詰まるまで/力尽きるまで続く）
```

## タッチ操作の想定（iPad/Android移植時。今回の実装はキーボードでよい）

- 移動・採掘: 画面下部の仮想8方向パッド（既に掘った床なら移動、未採掘タイルなら採掘）
- 攻撃: 移動パッドと独立した「攻撃ボタン」。タップで現在の向きへ攻撃
- スキル（範囲攻撃）: 別ボタン、クールダウン中はグレーアウト表示
- 帰還判断支援: 画面上部に「帰還推定燃料」「現在の脅威レベル」を常時表示するHUD（タップ操作なし、視認のみ）
- ショップ: 地上フェーズ時のみ画面全体にカテゴリ一覧を表示し、タップで購入（PC版のキー1〜8に対応）

## システム仕様

### ワールド

- 縦シャフト構造（003を踏襲）: 幅 `W=16`、深さ `H=161`（y=0が地上、y=1〜160が8バンド×20マス）
- タイル種別: `FLOOR`（既に掘った床・移動可）/ `DIRT`（柔らかい・低採掘威力で掘れる）/
  `ROCK`（硬い）/ `ORE_COPPER` / `ORE_IRON` / `ORE_GOLD`
- 003にあった `GAS` / `UNSTABLE` の環境ハザードタイルは今回**採用しない**。
  「掘るほど敵を呼ぶ」という戦闘由来の危険源と役割が重複するため、環境ハザードは敵に一本化し、
  コンテンツの水増しを避ける（CLAUDE.mdの水増し禁止方針に従う）
- 敵は「既に掘った床(FLOOR)」だけを移動でき、プレイヤーの掘った坑道そのものが戦闘のアリーナになる
  （002はアリーナが固定マップだったが、005ではプレイヤーの採掘パターンが動的にアリーナ形状を作る）

### プレイヤー（能力・リソース・成長）

- HP / 最大HP（戦闘・帰還遅延どちらでも減る共通リソース）
- 燃料（松明）/ 最大燃料: 003と同じ役割。受動的に減り、地上帰還で全回復。0になるとHPが減り始める
- 所持金・積載中の鉱石量/価値・最大積載量（003を踏襲）
- 採掘威力（drillPower）: 掘れるタイルの硬さ上限を決める（003の `requiredDrillPower` を踏襲）
- 攻撃力・攻撃クールダウン・最大HP・スキル（範囲攻撃、ショップで解禁）: 002を踏襲
- **掘削音（noise）**: 0〜100の内部値。同じ場所付近で掘り続けると上昇し、移動する・掘るのをやめると減衰する。
  この値が高いほど周辺での敵湧き確率が上がる。**AIP状態に数値公開**し、値そのものと「現在の推定追加湧き確率」を見て
  プレイヤー（AI）が「そろそろ移動すべきか」を判断できるようにする（003のestFuelToReturn公開パターンを踏襲）
- **estFuelToReturn**: 既に掘った床経由のBFS帰還距離から算出する帰還必要燃料（003と同じ実装をそのまま流用）

### 敵（種類・行動・スポーン）

- 敵は「既に掘った床(FLOOR)のうち、プレイヤーから一定距離離れたマス」を起点に、掘削音に応じた確率で湧く
- 深さ（バンド）が進むほど、敵の基礎湧き確率・HP・攻撃力が上昇する（002のwave倍率・003の深さスケーリングを踏襲し、
  最初から仕様に明記する。002→003で得た「後追い修正を避ける」学びを反映）
- 敵の移動は002と同じBFS経路探索＋プレイヤー隣接4マスへの「囲みスロット」分散割当てを踏襲する
  （002で発覚した「同一経路への渋滞で棒立ちがactiveより強くなる」逆転バグを最初から回避する）
- 種別は2種のみ（水増しをしない）: `crawler`（低HP・高頻度）、`brute`（高HP・低頻度・深いバンドで出現比率上昇）

### 経済（資源の入手と使い道の対応表）

鉱石を地上で売却して得た金で、常設ショップ（003方式。002のカードドラフットではなく、
「何度でも同じ項目を買い増せる」形式にすることで、002の課題「強化選択の分岐が2〜3回で終わりビルド差を検証できない」を
003実証済みのパターンで解消する）から以下を購入する。

| カテゴリ | 項目 | 効果 | 備考 |
|---|---|---|---|
| 採掘 | drill | 採掘威力+1 | 深い鉱石・岩を掘れるようになる |
| 採掘 | capacity | 最大積載+5 | 1トリップの稼ぎ上限 |
| 採掘 | fuel | 最大燃料+30 | 潜行できる時間 |
| 戦闘 | atk | 攻撃力+4 | |
| 戦闘 | hp | 最大HP+20（即回復込み） | |
| 戦闘 | atkspeed | 攻撃クールダウン-1（下限1） | |
| 戦闘 | skill | Lv1で範囲攻撃を解禁、以降はダメージ+8/CD-2（下限8） | 002のスキルを常設ショップ購入制に変更 |
| 共通 | muffler（防音マフラー） | 掘削で発生する掘削音の蓄積量-15%（下限-45%） | 採掘と戦闘の両カテゴリにまたがる橋渡しアイテム |

### 勝利/敗北条件

- 敗北: HPが0になる（ゲームオーバー）
- **単一の到達目標では終了しない**（004の積み残し「単一ゴール即終了で最適戦略のクリアが速すぎる」を踏まえた設計）。
  深さ40・80・120…とバンド境界ごとに「マイルストーン到達ボーナス」（一時金）を出すが、これはゲームを終了させない
  中間報酬に過ぎず、プレイは死ぬかティック上限まで続く終わりのない深掘りループとする
- スコア = 所持金+積載中価値 + maxDepth×係数 + 撃破数×係数（002/003のスコア式を踏襲）

### 実装中に判明したバランス調整（v1）

HP回復手段（自動回復・アイテム等）を一切用意していなかったところ、ヘッドレスシミュレーションで
「HPが危険域まで減り、かつ強化を買う金もない状態」に陥ったボットが、地上(y=0)と深度1の間を
1〜2tickおきに無限往復し続ける詰みループを起こすことを検出した（`tripsToSurface`が数千回に達する異常値で発覚）。
003・004のいずれも被弾源が環境ハザード中心で持続的ではなかったのに対し、005は敵との接敵が持続的なHP減少源になるため、
回復手段がないと詰みが恒常的に起こりうると判断し、地上滞在中に自動でHPが少しずつ回復する仕様
（LABOR_INCOMEと同じ「地上＝安全な回復地点」という役割を明確化するもの）をその場で追加した。

### v2 FIX内容（reviews/005-combat-mining-ironvein-v1.md 指摘への対応）

v1レビューで検出された3件の重大バグ・1件の中バグに対応した（詳細はreviews/005-combat-mining-ironvein-v2.md参照）。

1. **チョークポイント詰み**: 1マス幅の坑道が唯一の帰還経路を兼ね、敵に塞がれると長時間の消耗ループに
   陥る残存パターン（balanced seed9でtripsToSurface=3522）に対し、「緊急離脱(dash)」を新規実装。
   数値の安全マージン公開（estFuelToReturn）だけでは経路そのものが物理的に塞がれるケースを防げないため、
   「退路上の敵を無視して通過できる緊急手段」を構造的に追加した（購入不要・常時使用可能、HPコスト12・CD50tick）
2. **skillUses=0**: 価格引き下げ（baseCost40→25）だけでは、ボットの「優先度リスト先頭から買える項目を
   買い切ってから次へ」という購入方式自体が原因で解消しなかった。調査の結果、1マス幅の縦シャフトでは
   複数同時接敵(adjCount>=2)が構造的にほぼ発生しないことが判明したため、skillの役割を「複数同時接敵の
   保険」から「単体でもatk以上の価値を持つ強力な一手」へ再設計（ダメージ12→16、CD20→16tick）した
3. **死亡率過多**: 地上HP回復を1/tick→3/tickへ引き上げ。上記1・2の効果と合わせて、20シード比較で
   死亡率が50〜90%から0〜10%まで改善した
4. **combat-firstのmaxDepth=40の壁**: 再確認のみ実施。20シード全てで再現し、意図通りの「押し戻され方」
   として維持すると判断した

## AI評価の観点

- 「掘り続けるだけ（移動しない・敵を無視する）」と「移動を絡めて敵の湧きを分散させる」で、
  どちらが結果的に得か（前者が得なら移動インセンティブが機能していない）
- 採掘投資に全振り・戦闘投資に全振り・両方バランス投資、の3戦略比較で「両方に投資する意思決定の悩ましさ」が
  実際に生まれているか（002のA4「意思決定の悩ましさ」不足の解消を検証する）
- 敵の湧きに全く対応できず一方的に押し戻される「詰み」区間がないか
- 深いバンドに潜った際、敵の強さと得られる鉱石価値の釣り合いが取れているか（潜るほど得なのか損なのか）
- マイルストーンボーナスがあっても「そこで満足してやめてしまう」のではなく、続けて潜りたくなる設計になっているか
  （004の積み残し「単一ゴールで即終了」を繰り返していないか）
