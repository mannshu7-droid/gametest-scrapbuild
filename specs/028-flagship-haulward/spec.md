## コアファン仮説（1行）

> 昼の遠征で倒れた時に失う物を「その遠征でまだ持ち帰っていない積荷（鉱石＋撃破の懸賞）と揺れ」だけにし、揺れを凸の被ダメージに結びつけると、
> 防具・耐久への投資は「粘れる揺れの上限」として、塔への投資は「倒れても積荷の一部を守る・踏ん張りを戻す踊り場」として、救助ありでも価値を持つはず。

## コンセプト

- ジャンル / 視点: 2D横スクロール（上から見たレーン帯）、戦闘×採掘×建築＋昼夜サイクル防衛（本命ゲーム統合フェーズ・第十二世代）
- プレイ時間の想定: 1セッション20〜35分（20000tick、10tick/秒）。026と同一
- 参考にするゲーム: 026-flagship-tremorspire（ベース。全システムを継承）、027-combat-emberstake（救助の罰・凸の被ダメージ・踏ん張り・多芸の代償の移植元）

## コアループ

026と同じ（昼に採掘・戦闘で稼ぐ→拠点で強化・タレット・塔→夜にレイダーを防衛）。変わるのは「倒れた時に何を失うか」と「揺れが何を上げるか」:

- 拠点の外で**プレイヤーが倒した敵の報酬は「懸賞」として積荷に乗る**（026は即お金）。拠点へ持ち帰るまで確定しない＝027の残り火
- 揺れが高いほど売値・懸賞が上がり（026と同じ、最大+100%）、**同時に受けるダメージも凸で上がる**（揺れ45で×2、90で×5）
- HP0は救助。**失うのは抱えた積荷（鉱石＋懸賞）と揺れだけ**。お金・装備・時間（手当て）・ホームの耐久は失わない。ホームで目を覚ましてすぐ動ける
- **塔のパトロール圏（梁なしのレーン・梁の回廊）の中で倒れたら、積荷の半分は塔の見張りが拾ってホームへ届ける**
- **踏ん張り**: 拠点の外でHPが3割を割った瞬間、周りの敵を押し返し3秒間被ダメージ半分。**1日1回**（夜明けに戻る）。
  **梁で編んだ回廊（踊り場）に入ると、使った踏ん張りを1日1回だけ戻す**
- **防具**（新規ショップ、Fキー）: 被ダメージ×0.88/Lv。揺れの凸に掛け算で効くので、粘れる揺れの上限を動かす
- 身体の強化（攻撃力・耐久・防具・機動力）は**多芸は高くつく**: 他に持っている身体の強化1種ごとに価格×1.8

## システム仕様

026の全システムを継承する。調整値は`TUNE`（core/game.ts）にまとめ、`--tune key=value`で上書きできる。
**`--preset 026`（ブラウザは`?preset=026`）で026 v0.3.0と同じ規則**になり、026の出力と完全一致する（8戦略×8シードで確認）。

| 項目 | 式・値 | TUNE（026に戻す値） |
|---|---|---|
| 救助の形 | 失うのは抱えた積荷と揺れだけ。救助費0・手当て0・ホームへ | `stakeRescue=1`（0） |
| 懸賞 | 拠点の外でプレイヤーが倒した敵の報酬（揺れボーナス込み）を積荷の価値に足す。拠点に入ると換金 | `killToCargo=1`（0） |
| 凸の被ダメージ | プレイヤーへのダメージ（敵・落盤・危険タイル・塔の崩落）×(1+(揺れ/45)²) | `tremorDmg=1`（0）・`dmgDiv=45`・`dmgExp=2` |
| 防具 | 被ダメージ×0.88^Lv、8Lv、価格20×1.4^Lv | `armorMult=0.88`（1で売らない）。2回目の比較用に`armorFree`（多芸の代償の外）・`armorBase`（基本価格）・`armorConvex`（凸の部分だけ減らす）、既定は0/20/0＝v1と同じ |
| 多芸は高くつく | 身体の強化の価格×1.8^(他に持っている身体の強化の種類数) | `typePenalty=1.8`（1） |
| 踏ん張り | 拠点の外でHP<最大の3割になった瞬間に発動。半径2の敵を2マス押し返し攻撃を10tick遅らせ、30tick被ダメージ×0.5。1日1回 | `gritTicks=30`（0）・`gritFrac=0.3`・`gritDmgMult=0.5`・`gritPerDay=1` |
| 踏ん張りの受け止め（2回目） | 踏ん張りが残っていて、HP3割以上から一撃で1.5割を割る時、その一撃はHPを1.5割で止めて踏ん張りを発動させる（凸の被ダメージで窓を飛び越えない） | `gritCatch=1`（0） |
| 回廊で踏ん張りを戻す | 梁の回廊（woven）に入ると、使った踏ん張りを1日1回戻す | `gritRefill=1`（0） |
| 塔の見張りが積荷を拾う | 塔のパトロール圏（lane/woven）の中で倒れたら積荷の価値の50%を換金して届ける。**2回目: その遠征（拠点を出てから）で一度でも圏を通っていれば、どこで倒れても守る**（見張りが遠征を見送った） | `coverKeep=0.5`（0）・`coverTrip=1`（0。v1は0） |
| 安全地帯の上からは斬れない | 昼、拠点圏の中から圏の外の（レイダーでない）敵は攻撃できない | `baseNoAttack=1`（0） |

その他（揺れのたまり方・落盤・回廊/レーンの踊り場・夕暮れ・危険線45/注意線30・撃破ボーナス）は026と同じ値。

## タッチ操作の想定（iPad/Android、Capacitor移植時）

- 移動・攻撃・ダッシュ・建設・塔の操作は026と同じ（仮想スティック＋アクションボタン、塔パネルの長押し）
- 揺れゲージは画面上端に横長で常時表示し、その下に「抱えた積荷¥N」と被ダメージ倍率を大きく出す。倍率が×2を超えるとゲージの縁が赤く脈打ち、
  振動フィードバックを返す（数字を読まなくても「縁が赤い＝今倒れると積荷を全部失う」と分かる）
- その遠征で塔のパトロール圏を通った後は、積荷の数字の横に盾のアイコン（50%守る）を出し続ける（2回目）
- 踏ん張りの発動はプレイヤーの周りの青い輪＋短い強い振動。残り回数は揺れゲージの右端に点で表示
- 防具は拠点ショップの一覧から購入（多芸の代償で値上がりした価格を赤字で表示）

### 開発中の観察（初版の設計判断）

- 懸賞なし（撃破報酬は即お金）で先に回したところ、救助の損失がbare 45/ラン・救助3.2回で、戦う遊び方には失う物がほぼ無かった
  （撃破報酬が稼ぎの大半を占めるのに、積荷に乗らない）。027で成立したのは撃破の残り火が奉納まで未確定だったからなので、懸賞を積荷に乗せた
- 懸賞ありの40シードで、bareは塔の戦略（spireAll・weave）とp01に負けるようになったが、慎重な戦略（wall・mason・spire・p02）とpusherにはまだ勝つ（v1レビュー参照）

## AI評価の観点

- **合格線: 026と同じ8戦略（bareを対照群に）×80シード×2組の対比較で、bareが過半数で勝つ相手が無いこと**。同じ表を`--preset 026`でも取る。
  補助としてpusher（bareと同じ攻勢＋タレット）を加え、「同じ遊び方でタレットに払う価値」を切り分ける
- 2回目から、検証ボットの慎重な戦略は注意線30で帰る（`--carefulLine`）。対比較の前に、各戦略が自分の山で帰っているかを掃引で確かめる
- `--sweepAll`/`--returnAt`（帰着線の固定閾値30/45/60/75）と、`--tune armorMult=1`（防具なし）での同じ掃引: 防具が粘れる揺れの上限を動かすか
- `--bestPairs`: 前半シードで最良の閾値を選び、後半で対比較
- `--delay 30/60`: 迷う時間（3秒・6秒）の罰
- `--greedy 40`: 欲張り観察（tick3000以降の昼、揺れ40から帰らない）で倒れるまでの秒数・積荷の膨らみ・踏ん張りの発動
- ブラウザ: 単一HTML＋検証ボットで p01/p02 × seed 501〜503 がヘッドレスと一致するか、倒れた時の報告・踏ん張りの輪が見えるか
